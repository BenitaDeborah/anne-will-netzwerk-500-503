# Codebuch für SNA Midterm Special 

Wir untersuchen ein Netzwerk der Gäste von Anne Will und ihrer Parteizugehörigkeit. 

### Nodelist
ide = Initialen Vor- und Nachname, kleingeschrieben  
name = Voller Name  
type = 1 = Person, 2 = Organisation 


### edgelist 
from = Gast   
to = besuchte Show oder Parteimitgliedschaft  
relation = 1 = Sendungsgast, 2 = Parteimitgliedschaft
